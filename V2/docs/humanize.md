# xay V2 大白话事件文案与动效表

> 依据：`V2/docs/protocol.md` §4（事件目录）、§8（页面接口）。  
> 目标：供 `core/humanize.py` 格式化 `recent[].text` 及前端页面播放微动效。读者为不懂编程的老板。  
> 规则：
> 1. 每句 ≤ 30 个字。
> 2. 不出现英文术语、编号、文件路径。
> 3. 统一用词：员工、部门、计划、第几版、记忆、整理记忆、需要你、合并、保留。
> 4. 技术性与静默事件（如 `station.heartbeat`、`bridge.*`）统一标为“不显示”，无动画。
> 5. 后台按规则自动给员工下指令、写信、提醒的（账本里 by / from / to 是 `office` 或 `rules`：没做成让他接着修、文件重叠提醒、预算到了收尾、叫停 / 恢复、插话），页面上一律叫“监工”；公司页上这些信的虚线和写信飞行从收信员工所在部门的监工席出发（他没分部门时从总经理右边那位监工出发）。负责人命令行（`xay2 office …`）里那个后台进程仍叫“管家”，不归这张表管。
