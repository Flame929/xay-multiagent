# xay V2 使用说明

## 1. 一句话看懂 V2
把多个 AI 当成一家协同工作的软件公司：
- **总经理**：负责人 AI，负责听取你的要求、拆解任务、排活并最后验收成果。
- **员工**：干活的 AI（如 Codex、DeepSeek、Gemini），长期在岗，每人有一张固定的办公桌。
- **部门**：按工作划分的房间（如前端部、文档部），活分给对应的部门做。
- **管家**：背后常驻的小助手，自动选人、排活、送信、管记忆并看住预算。

## 2. 怎么打开页面与界面介绍
浏览器访问：`http://127.0.0.1:7879/org`（仅限本机访问，安全可靠）。

页面各个区域的作用：
- **顶栏**：展示当前项目、整体运行状态与全局操作。
- **总经理**：位于最上方，就是你在用的负责人 AI，活都从这里派下去。
- **部门房间与工位**：中间整齐排列各部门房间，每位员工有独立工位和电脑。
- **监工（规则监工）**：在后台按规矩盯着，遇到卡壳、死循环或超时会自动处理。
- **右侧面板**：
  - **信件**：员工、部门与总经理之间的沟通消息。
  - **任务拆解**：列出全部任务清单与目前做到第几步。
  - **计划版本**：每次调整任务的历史记录，谁在何时改了什么都能查。
- **员工详情（点员工的工位打开左侧栏）**：
  - 一眼看懂：目前在做哪件活、实时在想/在做什么、做到第几步。
  - 资源情况：额度还剩多少、记忆还剩多少、做完后的汇报，以及"他记住的事"。
- **看他的真实命令行（点工位电脑屏幕）**：
  - 点击工位上的电脑屏幕，会弹出一个小屏，实时看他敲的命令、思考与输出；再点小屏可以放大。
- **红色"全部停下"按钮**：
  - 页面右上角的紧急总闸，一点就能连同各家命令行一起立刻刹车，成果绝不丢失。

## 3. 员工状态说明
员工名片会显示清晰的状态词，一眼就能看懂：
- **干活中**：正在运行命令、修改文件或思考，全速干活。
- **排队中**：手上已有安排好的活，等前置任务完成或轮到自己就开工。
- **休息中**：手头活都做完了，在工位上随时待命。
- **整理记忆**：对话快满时主动写交接摘要并压缩记忆，防止变笨或失忆。
- **等你决定**：遇到保留改动处理或需要人拿主意的事，正等你定夺。
- **已阻塞 / 等人答复**：他问了问题或有"需要你"的事没处理，在等你回复。
- **上一轮失败**：上一轮没做成；连续报错、死循环这类会被管家自动叫停，不会白白浪费额度。
- **下班了 / 离线**：空闲时进程正常关闭（来活秒唤醒）；若显示崩溃则是异常离线。
- **已离职**：已被解雇，不再接活；他的桌子留着，只有你点头才会删。

## 4. 出现"需要你"时怎么选
当管家不能擅自做主时，会弹出"需要你"请你定夺，主要分两类：

### 甲类：保留下来的改动怎么办
当活没做成、被叫停、或结果跟预期不符但改了文件时，代码都安全留在桌上。固定三个选项：
- **合并改动（merge）**：改得挺好，把桌上的改动直接收进主项目。
- **让他接着改（rework）**：保留现有成果，让他在这个基础上继续改。
- **丢掉改动（discard，红色危险）**：不要这次改动，清空桌子避免影响后续。

### 乙类：其他要人拿主意的事
规则监工发现异常时提出（如额度用完、重试多次仍失败、员工一直复述不出记忆、很久没动静等）：
- 根据提示选择即可，常见选项包括：**再试一次**、**换个人做**、**加一些预算**、**打断或叫停**等。
- 选完后管家会自动按你的选择继续处理。

## 5. 常见问题
- **额度用完了怎么办？**
  - 系统有自动兜底：Codex 一条线路满载或用完，会自动换到另一条（Plus 和中转站互换）；Gemini 额度用完会自动换号（不限每天调用次数，按真实额度算）；
  - 若所有线路都用尽，系统会弹出"需要你"让你决定是换人做还是稍后再试，不会盲目报错。
- **员工"可能失忆"是什么意思？**
  - 每次压缩整理记忆后，管家会考考他"正在做什么、改过哪些文件、下一步是什么"；
  - 如果他答不上来，就会标上"可能失忆"，并重新发工作笔记让他再复述一遍，避免瞎改。
- **怎么全部停下和恢复？**
  - **停下**：点击页面右上角红色"全部停下"按钮，后台所有 AI 进程立刻暂停，已写的代码妥善保留；
  - **恢复**：如果在页面上拉下总闸，必须在页面上点击"恢复"才能继续开工，防止误操作。
